# Android 使用指南

[下载安装包](https://github.com/shixiang-liu/SNNU-AutoLogin/releases/download/android-v1.0.0/SNNU-AutoLogin-android.apk) · [返回项目首页](../README.md) · [开发与构建](../docs/android-development.md)

支持 **Android 8.0 及以上**，安装包不到 **60 KB**。连接学校 Wi-Fi 后，完成校园网认证与掉线重连，无需 Root 或 VPN。

## 第一次使用

1. 下载并安装 `SNNU-AutoLogin-android.apk`，在系统设置中连接学校 Wi-Fi。
2. 打开应用，填写学号、校园网密码，选择「校园网」「移动」或「联通」，点击「保存并连接」。账号无需填写 `@mobile` 等后缀。
3. 按需允许通知，之后可从通知栏直接连接或断开。需要锁屏后继续自动登录时，再检查 [后台运行](#后台运行) 设置。

首次从旧测试版切换到正式版，需要重新填写账号；两者的数据独立保存。

## 日常操作

| 操作 | 会发生什么 |
| :--- | :--- |
| 点击连接 | 检查认证，并开启自动登录 |
| 断开校园网 | 退出认证，同时关闭自动登录；Wi-Fi 保持连接 |
| 关闭「自动登录」 | 停止后台服务与通知，保留当前认证连接；重新开启后恢复自动登录 |
| 关闭应用界面 | 自动登录开启时，后台继续运行 |

首页显示当前账号与上网方式，在线时以学校认证页返回的会话为准。修改账号或上网方式前，会提示确认可能发生的短暂断网；验证未成功时保留原配置。

## 后台运行

在「设置 → 后台与通知」中查看通知和后台状态。需要持续重连时，按手机系统提供的选项允许后台运行；开机恢复默认关闭，可在这里按需开启。

- **通知**：用于查看连接状态，以及在通知栏快速连接或断开。
- **后台权限**：省电优化、后台限制与厂商电池设置可能是不同开关。应用能确认的状态会显示出来，无法读取的设置以系统页面为准。
- **开机恢复**：启用后，手机重启并首次解锁时尝试恢复自动登录。

系统休眠、厂商省电和自启动设置可能延迟重连。系统清理后台后，若自动登录仍为开启状态，重新打开应用可尝试恢复；手动关闭自动登录后，需要重新开启。

## 常见问题

### 已经连上 Wi-Fi，为什么还显示未登录？

连接 Wi-Fi 与校园网认证是两步。应用以学校认证页面的结果为准，可以在「设置 → 网络信息」点击「检查连接」重新读取状态。检查本身不会主动下线或重新登录。

### 上网方式怎么选？

与学校认证网页上的选择保持一致。密码错误或连接失败时，先核对账号、密码和上网方式；欠费、套餐异常或设备数超限需要在学校自助服务中处理。

### 网页要求验证码怎么办？

通过学校认证页面完成验证，再回到应用检查连接。浏览器可能使用移动数据，请保持连接学校 Wi-Fi，必要时使用系统提供的 Wi-Fi 登录入口。

### 怎么反馈问题？

在「设置 → 网络信息」导出脱敏诊断报告，附上手机型号、系统版本和复现步骤，提交到 [GitHub Issues](https://github.com/shixiang-liu/SNNU-AutoLogin/issues)。报告不包含密码，但分享前仍请检查 IP 等信息。

## 数据与隐私

账号与加密密码保存在本机，不上传给开发者。学校门户使用 HTTP，认证传输本身不加密。应用不使用广告、统计 SDK 或定位权限；认证和联网检测走 Wi-Fi，不回退到移动数据。

从源码构建、调度策略和认证细节见 [开发文档](../docs/android-development.md)，测试范围与性能数据见 [验证记录](VALIDATION.md)。
