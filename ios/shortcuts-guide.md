# iOS 快捷指令

照下面四步做完，连上 SNNU 就会自动登录，不用再点门户。全程十分钟，不需要电脑。

## 第 1 步：关掉系统自带的自动登录

「设置 → 无线局域网 → 点 `SNNU` 右边的 ⓘ」→ 关掉 **自动登录**，「自动加入」保持开着。

必须关的原因：系统会弹自己的门户面板抢着认证，和下面的快捷指令打架，结果是登录两次或者干脆没反应。

## 第 2 步：做一条「登录」快捷指令

打开「快捷指令」App → 右上角 `+` → 点顶部标题改名为 **校园网登录** → 按顺序添加这 6 个动作（在搜索框里搜动作名）：

| 顺序 | 搜什么 | 怎么设 |
| --- | --- | --- |
| 1 | 获取网络详情 | 不用设置 |
| 2 | 如果 | 输入选「网络详情」的 **网络名称**，条件「不是」，值填 `SNNU`；在「否则」里放 **停止此快捷指令** |
| 3 | 文本 | 填你的学号，然后长按改成变量名 `学号` |
| 4 | 文本 | 填你的密码，改成变量名 `密码` |
| 5 | 获取 URL 内容 | URL 填 `http://202.117.144.205:8601/snnuportal/login`，展开后方法选 **POST**，请求体选 **表单** |
| 6 | 如果 | 输入选第 5 步的 **内容**，条件「包含」，值填 `当前登录账号`；如果是 → 显示通知「校园网已连接」，否则 → 「登录失败，检查账号或端口」 |

第 5 步展开后，还要在「表单」下面加 5 个字段，一个都不能少：

| 字段名 | 值 |
| --- | --- |
| `sourceurl` | `null`（就填这四个字母，不是留空） |
| `account` | 变量 `学号` |
| `password` | 变量 `密码` |
| `yys` | 移动填 `mobile`，联通填 `unicom`，校园网直连就留空 |
| `issave` | 留空，但这一行要有 |

密码里含 `& = + % #` 时，在第 4 步和第 5 步之间插一个「URL 编码」动作，把 `密码` 编一次再用，否则表单会被截断。

**做完先手动验一次**：点右下角 ▶ 运行，应该弹出「校园网已连接」。这一步不通，后面自动化一定不通，先回来查字段和端口。

## 第 3 步：让它在你连上 SNNU 时自己跑

1. 「快捷指令」App 底部切到 **自动化** → 右上角 `+`；
2. 触发器列表里选 **无线局域网** → 「选取」→ 勾 `SNNU` → 选 **已连接**；
   别选「未连接」，那是掉线的那一刻，不是连上的那一刻。
3. 下一步 → 添加操作 → 搜 **运行快捷指令** → 选「校园网登录」；
4. 下一步 → 把 **运行前询问** 关掉（iOS 15 及以上可以彻底不弹）。

## 第 4 步：验证

关掉 Wi-Fi，再打开，连上 `SNNU`，等两三秒。顶部应该闪过快捷指令的运行横幅，然后弹「校园网已连接」。没反应就回第 3 步，确认触发器是「已连接」、动作选的是「校园网登录」。

到这一步就能日常用了。下面是可选的。

## 可选：查状态、断开

**校园网状态**：获取 URL 内容 `GET http://202.117.144.205:8601/snnuportal/userstatus.jsp` → 匹配文本 `id="account" value="([^"]*)"` → 如果有值就提醒「在线：{结果}」，没有就提醒「未登录」。

**校园网断开**：从菜单中选取（选项「确认断开」「取消」）→ 选确认就继续 → 获取 URL 内容 `GET http://202.117.144.205:8601/snnuportal/logoff`。断开后自动登录会停，需要再跑一次「校园网登录」恢复。

## 端口对不上怎么办

门户端口不是固定的，不同校区可能是 8601、8603、8605……上面统一写了 `8601`，手动运行报 404 或登录失败时，依次换成：

```
8601  8602  8603  8605  8609  8604  8606  8607  8608  8610  8600
```

改一处就行：第 2 步第 5 个动作的 URL，和可选指令里的 URL 一起改。

## 常见问题

- **手动运行就失败**：先看 URL 是不是 `/snnuportal/login`（带 `.jsp` 的是登录页，不是提交地址）。
- **表单发不出去**：五个字段缺一个，或者 `issave` 那行没建。
- **状态查不到账号**：正则里的双引号必须是英文引号。
- **换了地方就连不上**：端口变了，按上一节换端口。

## 限制

密码以明文存在快捷指令的「文本」动作里，开 iCloud 同步会同步到 iCloud，拿到已解锁设备的人也能看到。介意就关掉这条指令的 iCloud 同步，或者每次手动输入。

Wi-Fi 触发器只在连上网络的瞬间执行一次；用着用着会话过期了它不会自己补，需要点一下「校园网登录」。这是 iOS 的限制，不是配置问题。
