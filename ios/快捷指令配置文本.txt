================================================================
  陕Star 校园网 · iPhone 快捷指令配置文本（免安装 App）
================================================================

给谁用：iPhone 连接校园网 Wi-Fi「SNNU」的用户。
做什么：把下面三条"快捷指令"照抄搭好，以后连上 SNNU 网就自动登录，
        也能一键查状态、一键断开。不用装任何 App、不用签名、不用电脑。

----------------------------------------------------------------
准备（一次性，30 秒）
----------------------------------------------------------------
手机打开「快捷指令」App（图标是两个彩色方块，所有 iPhone 都自带）。

----------------------------------------------------------------
指令一：校园网登录（核心，必做）
----------------------------------------------------------------
快捷指令 App → 右上角 + 新建 → 右上角重命名为「校园网登录」

按顺序添加以下动作（在下方搜索框输入动作名即可找到）：

  动作 1：【获取网络详情】
          不用配置任何参数。首次运行会弹窗要权限，点允许。

  动作 2：【如果】
          条件：网络详情 的 网络名称  是  SNNU
          （在"如果"的第二个框选"是"）
          → 这一步之后的所有动作都放在 如果/结束如果 之间

  动作 3：【文本】
          内容填：你的学号
          填完长按这个文本动作 → 重命名变量 → 改名为：学号

  动作 4：【文本】
          内容填：你的校园网密码
          同样重命名变量为：密码

  动作 5：【从菜单中选取】
          菜单项三个：移动 / 校园网 / 联通
          （运营商是移动填移动、联通填联通、校园网卡或不确定选校园网）
          → 菜单结果重命名变量为：yys

  动作 6：【获取 URL 内容】（核心，照抄）
          URL：http://202.117.144.205:8601/snnuportal/login
          展开箭头 → 方法选 POST
          请求体 → 选"表单"→ 添加 5 个字段（名字和值完全一致，顺序照抄）：

            sourceurl  =  null
            account    =  （选变量：学号）
            password   =  （选变量：密码）
            yys        =  （选变量：yys）
            issave     =  （留空！这一行必须有，值空着）

          展开最底部 → 关闭"自动重定向"不用管；
          "显示更多"里若出现"请求头"不用填。

  动作 7：【如果】
          条件：动作 6 的输出  包含  当前登录账号
          → 是：【显示提醒】内容：登录成功 ✓
          → 否：【显示提醒】内容：登录失败，请检查密码或运营商
                （可以再插一个"文本"动作把动作 6 的输出接进来看详情）

搭好后点运行测试一次（要在校园网内、连着 SNNU Wi-Fi）。

----------------------------------------------------------------
指令二：校园网状态（查当前在不在网）
----------------------------------------------------------------
新建快捷指令 → 重命名「校园网状态」

  动作 1：【获取 URL 内容】
          URL：http://202.117.144.205:8601/snnuportal/userstatus.jsp
          方法：GET（默认）

  动作 2：【匹配文本】
          待匹配文本：动作 1 的输出
          正则表达式：id="account" value="([^"]*)"
          → 命中的就是你的账号（如 20240001@mobile）

  动作 3：【如果】
          条件：匹配结果  为空  （匹配次数 = 0）
          → 是：【显示提醒】当前不在校园网内
          → 否：【显示提醒】在线中：账号 xxx

（进阶：再加两个【匹配文本】用 id="ipaddr" value="([^"]*)"
  提取 IP，用 [0-9]{4}-[0-9]{2}-[0-9]{2} [0-9:]{8} 提取登录时间，
  把它们拼进提醒里。）

----------------------------------------------------------------
指令三：校园网断开（下线用）
----------------------------------------------------------------
新建快捷指令 → 重命名「校园网断开」

  动作 1：【要求输入】提示文字：确定要断开校园网吗？
          输入类型：选"确认/取消"
  动作 2：【如果】输入 等于 OK/确定
  动作 3：【获取 URL 内容】
          URL：http://202.117.144.205:8601/snnuportal/logoff
          方法：GET
          注意：结尾就是 /logoff，没有 .jsp，不要多打字
  动作 4：【显示提醒】已请求断开

----------------------------------------------------------------
自动化：连上 SNNU 自动登录（等效自动联网）
----------------------------------------------------------------
快捷指令 App → 底部「自动化」→ 新建 → 选「无线局域网」
→ 选 SNNU → 关闭"运行前询问"→ 动作选「运行快捷指令」→ 校园网登录

效果：每次手机连上 SNNU Wi-Fi 的瞬间，自动完成门户登录。

兜底（可选）：再建一条自动化 → 「时间」触发（如每天早上 8 点）
→ 运行「校园网登录」。登录是幂等的，已在线时重复执行无副作用。

----------------------------------------------------------------
常见问题
----------------------------------------------------------------
· 登录失败 404？  检查 URL 是否抄错（8601、/snnuportal/login）
· 表单老是发不出去？确认 5 个字段都在、issave 行留空但存在
· 提取不到账号？  正则里的双引号必须是英文引号
· 在宿舍但不在校园网范围？  看不到 SNNU 时指令一会在动作 2 停止，
  这是正常保护，不会乱发请求
· 运营商选错了？  移动/联通选错会认证失败，重新运行选对即可；
  "校园网"指不挂运营商的校园直连账号

端点速查（排障用）
----------------------------------------------------------------
登录    POST http://202.117.144.205:8601/snnuportal/login
状态    GET  http://202.117.144.205:8601/snnuportal/userstatus.jsp
断开    GET  http://202.117.144.205:8601/snnuportal/logoff
备用端口：以上 8601 全部可换 8602（主端口不通时）
成功标志：返回内容包含「当前登录账号」
