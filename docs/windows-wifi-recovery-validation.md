# Windows Wi-Fi 自愈开发验证

发布版本：Windows `v1.1.0`；开发基线：`933281d`。macOS 与 Android 的版本、发布包不变。

## 实现范围

- 独立实现，使用系统 WLAN API，不执行 Gitee 分支代码，也未合并 PR #2。
- 设置页增加默认关闭的「自动连接学校 Wi-Fi」，目标为系统已保存且当前可见的 `SNNU`。
- 保护已有有线连接、其他 Wi-Fi、正在关联的无线网卡，以及不可读取的网络状态。
- 失败或未完成的连接请求至少间隔 60 秒，DHCP 等待窗口 45 秒；确认 Wi-Fi 关联成功后清除本轮冷却，之后新的断线不受旧请求影响。门户探测不等待连接冷却。
- 无目标时每 15 秒查询；WLAN ACM 的断开、连接结果、扫描完成及网络可用事件可提前唤醒。只订阅 ACM，不申请 MSM 通知所需的位置相关权限。监听失败则记录原因并保留轮询。
- 无物理 IPv4 时先尝试 Wi-Fi 恢复，不先等待门户和外网 HTTP 超时；保留已有有线和 Wi-Fi 连接的保护。
- 无新增常驻线程、第三方依赖或系统配置修改；暂停与连接动作共用现有连接锁并在提交前重读状态。
- 账号状态缺失或损坏时不猜测用户意图，不自动连接或恢复本轮认证。
